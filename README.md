# ระบบสต๊อกแก้ว (เวอร์ชัน Firebase + GitHub Pages)

ไฟล์ในโฟลเดอร์นี้:
- `index.html` — เว็บแอปทั้งหมด (ไฟล์เดียว มีข้อมูลสินค้าเริ่มต้น 332 รายการฝังไว้แล้ว)
- `firestore.rules` — กฎความปลอดภัยของฐานข้อมูล (ใครดูได้/แก้ไขได้)

ใช้ **Firebase (แผนฟรี Spark)** เป็นฐานข้อมูล + ระบบล็อกอิน ไม่มีค่าใช้จ่ายสำหรับการใช้งานระดับนี้

---

## ขั้นตอนตั้งค่า (ทำครั้งเดียว)

### 1) สร้างโปรเจกต์ Firebase
1. ไปที่ https://console.firebase.google.com → **Add project** → ตั้งชื่อโปรเจกต์ (เช่น `stock-glass`)
2. ปิด Google Analytics ได้ (ไม่จำเป็น) → Create project

### 2) เปิดใช้ระบบล็อกอิน (Authentication)
1. เมนูซ้าย → **Build → Authentication** → Get started
2. แท็บ **Sign-in method** → เลือก **Google** → Enable → Save

### 3) เปิดใช้ฐานข้อมูล (Firestore)
1. เมนูซ้าย → **Build → Firestore Database** → Create database
2. เลือก **Start in production mode** → เลือก location ใกล้ที่สุด (เช่น `asia-southeast1`) → Enable

### 4) ตั้งกฎความปลอดภัย
1. ในหน้า Firestore → แท็บ **Rules**
2. เปิดไฟล์ `firestore.rules` ที่แนบมา แก้ `owner@example.com` เป็น **อีเมล Gmail จริงของผู้ดูแลหลัก** (คนที่จะเพิ่ม/ลบสิทธิ์คนอื่นได้)
3. วางทั้งหมดแทนของเดิมในกล่อง Rules → กด **Publish**

### 5) เอาโค้ด config มาใส่ในเว็บ
1. เมนูซ้าย → ⚙️ **Project settings** → เลื่อนลงหา **Your apps** → กดไอคอน **</>** (Web app)
2. ตั้งชื่อ nickname อะไรก็ได้ → Register app (ไม่ต้องติ๊ก Hosting)
3. จะได้โค้ด `firebaseConfig = {...}` ก้อนหนึ่ง → คัดลอกทั้งหมด
4. เปิดไฟล์ `index.html` ด้วยโปรแกรมแก้ไขข้อความ ค้นหาคำว่า `YOUR_API_KEY` แล้ว **แทนที่ทั้งก้อน** `firebaseConfig` ด้วยค่าที่คัดลอกมา
5. ในบรรทัดถัดมา แก้ `SUPERADMIN_EMAIL = "owner@example.com"` ให้เป็น**อีเมลเดียวกับข้อ 4 ของขั้นตอนที่ 4** (ต้องตรงกันทุกตัวอักษร)

### 6) เอาขึ้น GitHub Pages
1. สร้าง repo ใหม่บน GitHub (public หรือ private ก็ได้ ถ้า private ต้องใช้ GitHub Pro ถึงจะเปิด Pages ได้)
2. อัปโหลด `index.html` ขึ้น repo (จะไว้ที่ root หรือโฟลเดอร์ `/docs` ก็ได้)
3. ไปที่ repo → **Settings → Pages** → Source เลือก branch และโฟลเดอร์ที่วางไฟล์ → Save
4. รอ 1–2 นาที จะได้ลิงก์ประมาณ `https://ชื่อบัญชี.github.io/ชื่อ-repo/`

### 7) โหลดข้อมูลเริ่มต้นเข้าฐานข้อมูล
1. เปิดลิงก์ GitHub Pages ที่ได้ ด้วยบัญชี Gmail เดียวกับ `SUPERADMIN_EMAIL`
2. กด **"เข้าสู่ระบบเพื่อแก้ไข"** → ล็อกอิน Google
3. จะเห็นแผง **⚙️ แผงผู้ดูแล** ด้านบน → กดปุ่ม **"โหลดข้อมูลเริ่มต้นจากไฟล์ Excel (332 รายการ)"** (กดครั้งเดียวพอ)

### 8) เพิ่มพนักงานโรงงานที่ให้แก้ไขได้
ในแผงผู้ดูแลเดียวกัน มีช่องใส่อีเมล Gmail ของพนักงาน → กด **"เพิ่มสิทธิ์แก้ไข"**
พนักงานคนนั้นแค่เปิดลิงก์เว็บ แล้วกด "เข้าสู่ระบบเพื่อแก้ไข" ด้วย Gmail ของตัวเอง ก็จะแก้ไขได้ทันที

## การใช้งานปกติ (หลังตั้งค่าเสร็จ)
- **คนทั่วไป**: เปิดลิงก์ดูสต๊อกได้เลย ไม่ต้องล็อกอิน แก้ไขไม่ได้
- **พนักงานที่มีสิทธิ์**: ล็อกอิน Gmail แล้วจะเห็นปุ่มเพิ่ม/แก้ไข/ลบสินค้า และอัปโหลดรูปใหม่ได้
- **ผู้ดูแลหลัก (SUPERADMIN_EMAIL)**: เห็นแผงจัดการสิทธิ์เพิ่ม/ลบพนักงานที่แก้ไขได้ทุกเมื่อ
- ข้อมูลซิงก์เรียลไทม์ทุกคนที่เปิดหน้าอยู่

## หมายเหตุ
- ค่าใช้จ่าย: แผนฟรีของ Firebase (Spark) รองรับการอ่าน/เขียนหลักหมื่นครั้งต่อวัน เพียงพอสำหรับใช้งานในโรงงานทั่วไป
- ถ้าอยากลบผู้ดูแล/เปลี่ยนอีเมลหลัก ต้องแก้ทั้งใน `firestore.rules` (แล้ว Publish ใหม่) และใน `index.html` (`SUPERADMIN_EMAIL`) ให้ตรงกัน
- ไฟล์ `index.html` มีข้อมูล apiKey ของ Firebase อยู่ในโค้ด — ไม่เป็นอันตราย เพราะ Firebase ออกแบบมาให้ apiKey เปิดเผยต่อสาธารณะได้ ความปลอดภัยจริงอยู่ที่ `firestore.rules`
